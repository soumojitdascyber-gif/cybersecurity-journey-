# TA0042 - Resource Development

## What is Resource Development?

Resource Development is the stage where attackers prepare infrastructure and resources before attacking a target.

Goal:

- Build attack infrastructure
- Register domains
- Create phishing resources
- Prepare malware

This stage happens before Initial Access.

---

## Attacker Objectives

- Create phishing websites
- Register malicious domains
- Purchase VPS servers
- Build malware infrastructure

---

## Common Resource Development Techniques

### 1. Acquire Infrastructure (T1583)

Examples:

- VPS Servers
- Cloud Servers
- Bulletproof Hosting

---

### 2. Acquire Domains (T1583.001)

Examples:

- microsoft-login-support.com
- secure-office365-login.com

Goal:

- Phishing
- Malware Delivery

---

### 3. Obtain Capabilities (T1587)

Examples:

- Malware
- Exploits
- Phishing Kits

---

### 4. Develop Accounts (T1585)

Examples:

- Fake Social Media Accounts
- Fake Email Accounts

---

### 5. Stage Capabilities (T1608)

Examples:

- Upload malware
- Configure phishing infrastructure
- Setup C2 server
