# Phishing Types and Analysis

This repository contains structured notes on various phishing attack techniques, investigation methods, detection strategies, and SOC analyst perspectives.

## Topics Covered

- Email Phishing
- Spear Phishing
- Whaling
- Smishing
- Vishing
- Clone Phishing
- Business Email Compromise (BEC)
- OAuth Phishing
- Pharming
- MFA Fatigue Attack
- Attachment-Based Phishing
- URL-Based Phishing

## Purpose

To build a strong understanding of phishing attacks from a SOC Analyst and Blue Team perspective.
