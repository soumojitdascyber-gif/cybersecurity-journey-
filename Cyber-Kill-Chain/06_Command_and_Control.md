# Command and Control (C2)

## Definition
The attacker establishes communication with the compromised system to issue commands remotely.

## Common Techniques
- HTTP/HTTPS
- DNS Tunneling
- Reverse Shell
- Beaconing

## Detection
- DNS Logs
- Proxy Logs
- Firewall Logs
- Network Traffic Analysis

## MITRE ATT&CK
TA0011 - Command and Control
