# Reconnaissance

## Definition
Reconnaissance is the first phase of the Cyber Kill Chain where attackers gather information about a target before launching an attack.

## Common Techniques
- OSINT
- Google Dorking
- WHOIS Lookup
- DNS Enumeration
- Social Media Research

## Detection
- Monitor scanning activity
- Detect unusual DNS queries
- Analyze web server logs

## MITRE ATT&CK
TA0043 - Reconnaissance
