# Weaponization

## Definition
Weaponization is the stage where attackers combine an exploit with a malicious payload to create a weapon for attacking the target.

## Common Techniques
- Malware Creation
- Malicious Office Documents
- Exploit Kits
- Payload Generation

## Detection
- Sandbox Analysis
- Malware Scanning
- Threat Intelligence
