# Actions on Objectives

## Definition
In the final stage, the attacker achieves the intended objective, such as stealing data, encrypting files, or disrupting services.

## Common Techniques
- Data Exfiltration
- Ransomware
- Credential Theft
- Lateral Movement

## Detection
- DLP Alerts
- EDR Alerts
- SIEM Correlation
- File Activity Monitoring

## MITRE ATT&CK
TA0010 - Exfiltration
TA0040 - Impact
